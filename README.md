

تأكد من تثبيت البرامج التالية على جهازك قبل البدء:

Node.js (إصدار 18 أو أحدث).

PostgreSQL (لتشغيل قاعدة البيانات).

npm (مدير الحزم المدمج مع Node.js).

ngrok (لربط السيرفر بالإنترنت).

🚀 خطوات التشغيل (Setup Guide)

الخطوة 1: تجهيز قاعدة البيانات عبر التيرمنال (Terminal)

لكي يعمل الكود دون الحاجة لتعديل ملفات البيئة، سنقوم بإنشاء قاعدة بيانات ومستخدم بنفس الأسماء المعتمدة في المشروع.
افتح التيرمنال (Terminal) ونفذ الخطوات التالية:

الدخول إلى سطر أوامر PostgreSQL بصلاحيات المستخدم الافتراضي (postgres):

sudo -u postgres psql



نفذ أوامر الـ SQL التالية (انسخها والصقها، ثم اضغط Enter):

-- إنشاء المستخدم وكلمة المرور
CREATE ROLE mohammed WITH LOGIN PASSWORD 'mohammed_123';

-- إعطاء المستخدم صلاحيات إنشاء قواعد البيانات
ALTER ROLE mohammed CREATEDB;

-- إنشاء قاعدة البيانات وربطها بالمستخدم
CREATE DATABASE hadante_db OWNER mohammed;



للخروج من شاشة PostgreSQL والعودة للتيرمنال العادي، اكتب:

\q



الخطوة 2: تنزيل المشروع وتثبيت الحزم

في التيرمنال، نفذ الأوامر التالية لسحب الكود والدخول للمجلد وتنزيل الحزم:

git clone https://github.com/mohammedOdeh12/hadante-backend.git
cd hadante-backend
npm install



الخطوة 3: إعداد المتغيرات البيئية (.env)

في المسار الرئيسي للمشروع، قم بعمل نسخة من ملف .env.example.

أعد تسمية النسخة لتصبح .env فقط.

لا تقم بتعديل أي شيء داخل الملف! الإعدادات الموجودة فيه جاهزة ومربوطة بالمستخدم وقاعدة البيانات التي أنشأناها في الخطوة الأولى.

الخطوة 4: تشغيل السيرفر

وأنت داخل مجلد المشروع في التيرمنال، اكتب الأمر التالي لتشغيل المشروع:

npm run dev



ملاحظة: عند تشغيل السيرفر لأول مرة، ستقوم أداة TypeORM تلقائياً بالاتصال بقاعدة البيانات الفارغة (hadante_db) وإنشاء جميع الجداول المطلوبة (Users, Roles, Nurseries, إلخ...).

الخطوة 5: ربط الباك إند بالفرونت إند (عبر Ngrok)

السيرفر الآن يعمل محلياً على المنفذ 5000. لكي يستطيع تطبيق الفرونت إند الاتصال به:

افتح نافذة تيرمنال جديدة (مع إبقاء نافذة السيرفر تعمل).

اكتب الأمر التالي:

ngrok http 5000



سيظهر لك رابط عام (يبدأ بـ https://).

انسخ هذا الرابط، واذهب إلى مشروع الفرونت إند، وافتح ملف .env الخاص به، وأضف الرابط كالتالي:

NEXT_PUBLIC_API_URL=الرابط_الذي_نسخته_هنا



💡 ملاحظة للمطورين: قاعدة البيانات التي تم إنشاؤها ستحتوي على الهيكلية الصحيحة (الجداول والعلاقات) ولكنها ستكون فارغة من البيانات. لاختبار النظام، ستحتاج إلى إضافة بيانات وهمية (مثل إنشاء حسابات أو حضانات) إما عبر واجهة المستخدم (الفرونت إند) أو باستخدام أداة مثل Postman.
